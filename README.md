# 🌐 Social Icons

Interactive Social Icons built with HTML and CSS featuring smooth hover animations, username tooltips, follow buttons, and a clean modern UI.

## ✨ Features

- Interactive social media icons
- Smooth hover animations
- Username tooltip effects
- Follow button animation
- Blur effect on inactive icons
- Modern responsive design
- Pure HTML & CSS
- Beginner-friendly project

## 🚀 Technologies Used

- HTML5
- CSS3
